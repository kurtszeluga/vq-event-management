GoDaddy Event Feed Demo

This is a draft embeddable version of the public events listing. If this looks right, we can use the same feed on a GoDaddy test page without finishing the whole registration workflow first.

Paste this into a GoDaddy HTML block: 
<div
  data-vq-feed
  data-category="events"
  data-source-url="https://vq-event-management.vercel.app/api/public-events"
></div>
<script src="https://vq-event-management.vercel.app/godaddy-event-feed.js" defer></script>

One row of pills renders above the feed — Programs, Workshops, Challenges, Business Listings, For Sale — and data-category decides which starts selected (programs, workshops, challenges, business, forsale). Add data-categories to limit or reorder them, for example data-categories="workshops,forsale". Listing a single one hides the row altogether, which is how you pin an embed to one kind of listing.

data-layout picks the card geometry: roster (the default — one listing per row with a large photo), grid (photo-forward tiles that reflow to the column width), or agenda (dense scannable rows, worth using once a page carries a dozen-plus listings). The card content is chosen separately, by listing type: events show seats and cost, For Sale leads with the asking price, and Business Listings are a contact block.

One page per listing type: 
<!-- Programs & Workshops page -->
<div data-vq-feed data-category="programs" data-categories="programs,workshops" data-layout="roster"></div>

<!-- Challenges page -->
<div data-vq-feed data-category="challenges" data-categories="challenges" data-layout="roster"></div>

<!-- For Sale page -->
<div data-vq-feed data-category="forsale" data-categories="forsale" data-layout="grid"></div>

<!-- Business Listings page -->
<div data-vq-feed data-category="business" data-categories="business" data-layout="grid"></div>

Each snippet still needs its own data-source-url and the <script> tag from the block above.
